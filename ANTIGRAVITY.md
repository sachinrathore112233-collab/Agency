## 📐 Project Conventions for AGY

When prompting Antigravity within this project, use the following conventions:

### Component Generation
```
Generate a [ComponentName] React component using:
- Next.js App Router
- Tailwind CSS for styling
- Framer Motion for entrance animations
- TypeScript with proper types
```

### Animation Patterns
- **Page transitions**: Framer Motion `AnimatePresence`
- **Scroll animations**: GSAP `ScrollTrigger`
- **Micro-interactions**: Framer Motion `whileHover` / `whileTap`
- **Text reveals**: GSAP `SplitText` or Framer Motion character stagger

### Naming Conventions
- Components: `PascalCase` (e.g., `HeroSection.tsx`)
- Utilities: `camelCase` (e.g., `formatDate.ts`)
- CSS classes: Tailwind utilities, no custom CSS unless necessary
- Animation variants: `camelCase` with `Variants` suffix (e.g., `fadeInVariants`)
